# 🎨 Unicoin Brand Guidelines

## Overview

Unicoin's visual identity is designed to represent the cutting-edge technology, security, and innovation that defines the world's most advanced cryptocurrency platform. Our branding reflects quantum-resistant cryptography, AI-powered features, and the future of decentralized finance.

## 🎯 Brand Positioning

**Unicoin** is positioned as:
- The most advanced cryptocurrency platform
- Quantum-resistant and AI-powered
- Professional, trustworthy, and innovative
- The future of decentralized finance

## 🎨 Color Palette

### Primary Colors
- **Unicoin Blue**: `#00D4FF` - Primary brand color representing technology and trust
- **Deep Blue**: `#0099CC` - Secondary color for depth and professionalism
- **Navy Blue**: `#003366` - Accent color for stability and security

### Secondary Colors
- **Unicoin Gold**: `#FFD700` - Premium color for highlights and success
- **Orange**: `#FFA500` - Energy and innovation
- **Deep Orange**: `#FF6B00` - Action and advancement

### Neutral Colors
- **Pure White**: `#FFFFFF` - Clean and modern
- **Light Blue**: `#F0F8FF` - Soft background
- **Pale Blue**: `#E6F3FF` - Subtle highlights

### Usage Guidelines
- Use Unicoin Blue as the primary color for logos and key elements
- Use Gold for highlights, success states, and premium features
- Maintain high contrast ratios for accessibility
- Avoid using more than 3 colors in a single design

## 🔤 Typography

### Primary Font
- **Font Family**: Arial, Helvetica, sans-serif
- **Usage**: Headlines, titles, and important text
- **Weights**: Bold (700), Regular (400)

### Secondary Font
- **Font Family**: 'Courier New', monospace
- **Usage**: Code, technical documentation, addresses
- **Weights**: Regular (400), Bold (700)

### Typography Scale
- **H1**: 48px / 3rem (Bold)
- **H2**: 36px / 2.25rem (Bold)
- **H3**: 24px / 1.5rem (Bold)
- **Body**: 16px / 1rem (Regular)
- **Small**: 14px / 0.875rem (Regular)
- **Code**: 14px / 0.875rem (Monospace)

## 🏷️ Logo Usage

### Logo Components
The Unicoin logo consists of:
1. **Circular Background**: Gradient from Unicoin Blue to Navy Blue
2. **Inner Circle**: Light blue/white gradient
3. **U Symbol**: Gold gradient representing "Unicoin"
4. **Quantum Dots**: Animated processing nodes
5. **Neural Connections**: Lines connecting the dots
6. **Orbital Ring**: Rotating processing elements

### Logo Variations

#### Primary Logo
- Full logo with all elements
- Use for main branding and marketing
- Minimum size: 120px width

#### Simplified Logo
- U symbol only with background circle
- Use for small spaces and icons
- Minimum size: 60px width

#### Monochrome Logo
- Single color version
- Use for single-color applications
- Available in white, black, and Unicoin Blue

### Logo Placement
- Maintain clear space equal to the height of the U symbol
- Never place on busy backgrounds
- Ensure sufficient contrast
- Don't modify colors or proportions

### Visual Elements
- **Quantum-inspired patterns**: Representing advanced cryptography

- **Geometric shapes**: Clean, modern, and technical
- **Gradient backgrounds**: Sophisticated and premium feel

- **Technology-focused**: Showcasing innovation

## 📱 Application Guidelines

### Digital Applications
- **Websites**: Use primary logo with full color palette
- **Mobile Apps**: Adapt logo size for different screen densities
- **Social Media**: Use appropriate logo variation for each platform
- **Email**: Maintain brand colors and typography

### Print Applications
- **Business Cards**: Use simplified logo with full color
- **Brochures**: Maintain brand guidelines for all text and imagery
- **Banners**: Use high-resolution logos and maintain proportions
- **Signage**: Ensure readability at all sizes

### Technical Specifications
- **Logo Formats**: SVG (preferred), PNG, PDF
- **Resolution**: Minimum 300 DPI for print, 72 DPI for web
- **Background**: Transparent PNG for overlays
- **Color Space**: RGB for digital, CMYK for print

## 🚫 Brand Misuse

### What NOT to Do
- ❌ Don't change logo colors
- ❌ Don't stretch or distort the logo
- ❌ Don't use low-resolution versions
- ❌ Don't place on busy backgrounds
- ❌ Don't modify the U symbol design
- ❌ Don't use outdated logo versions
- ❌ Don't combine with competing brand colors

### Common Mistakes to Avoid
- Using incorrect color values
- Placing logo too close to other elements
- Using wrong typography
- Inconsistent spacing
- Poor contrast ratios
- Outdated design elements

## 📊 Brand Consistency Checklist

### Before Publishing
- [ ] Colors match brand palette exactly
- [ ] Typography follows guidelines
- [ ] Logo is current and properly sized
- [ ] Sufficient contrast for accessibility
- [ ] Clear space around logo maintained
- [ ] Brand voice and tone consistent
- [ ] Imagery aligns with brand style
